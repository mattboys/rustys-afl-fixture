PAIRING DEFINITIONS

How the six are formed

RRegular

Fixed rivalry match-ups played twice regardless of ladder position.

AAssigned

Opponents from the same previous-season ladder bracket.

CConditional

An extra double-up when a Regular opponent is already in the same bracket, or where a bracket has only three clubs. The missing choice is explicitly unresolved.

INPUT REQUIRED
PROPOSED EXACT METHOD

Constraint programming with lexicographic optimisation

Use a CP-SAT solver such as OR-Tools. First find a schedule satisfying every absolute rule. Only then optimise the preferential rules and, as a final tie-break, minimise changes to mutable base assignments.

01

Freeze the input

Represent each supplied slot, bye, venue and broadcast assignment. Lock immutable rows; preserve NOT LOCKED pairings while allowing their documented time or venue changes. Treat restricted-opponent lists as exhaustive domains.

02

Define decision variables

x[t,o,r] selects an unordered opponent pair in round r; h[t,o,r] chooses who hosts; v[g,s] assigns venue/time slot s to game g; b[t,r] records a bye.

03

Add hard constraints

One match or bye per team-round; 24 matches, 12 Home, 12 Away, 3 Byes; six double-up opponents and twelve single-up opponents; home/away orientation, bye windows, streaks, rematch spacing, venue eligibility and same-day ground capacity.

04

Optimise in order

Keep all A-rules hard. Maximise P1 pair balance first, then P2 interstate Home/Away alternation. Use the fewest edits to allowed base fields as a deterministic tie-break, never relaxing a hard rule to improve a preference.

05

Independently audit

Run every rule over the final emitted schedule, including dates and venue/day collisions. Report each failure with team, round and source rule; never convert an unknown input into a pass.

FORMAL SHAPECP-SAT / 0-1 VARIABLES
For every team t and round r:
  sum(opponent games for t in r) + bye[t,r] = 1
  sum_r bye[t,r] = 3
  sum(home games for t) = sum(away games for t) = 12

For every unordered pair {t,o}:
  sum_r game[{t,o},r] in {1, 2}
  exactly 6 pairs have count 2; exactly 12 have count 1
  if count = 2: host orientation is opposite; rounds differ by >= 5

Hard constraints: A1-A14
Objective: lexicographically maximize (P1, P2, -mutable_base_changes)
i
Why CP-SAT, not a greedy fill?

Assignments interact globally: choosing an opponent consumes two teams' round capacity, changes both travel streaks, and may force a venue or rematch elsewhere. A greedy local choice can dead-end late; constraint propagation exposes contradictions early and supports explainable infeasibility checks.

A13 requires at least five full days off between games. Rounds alone do not determine the date difference, especially where round-specific scheduling spans unusual weekdays.
