## Legend

- **LOCKED** = Match is fixed and cannot be moved
- **NOT LOCKED** = Match-up is set but time/venue may change
- **RESTRICTED** = The opponent must be selected from the documented eligible list below
- **TBD** = Opponent to be determined by the algorithm
- **Unlabelled** = A displayed base-fixture assignment with no additional lock status; retain it unless a rule requires an allowed adjustment.
